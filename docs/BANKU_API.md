# Обмен между Banku Bot и Banku

Бот отправляет `POST /api/bot/v1` на частный сайт Banku. Это узкий сервисный интерфейс: он не
изменяет BAC, счета, комиссии или банковские права.

## Подпись

Тело JSON подписывается по **исходным байтам**. Заголовки:

- `x-banku-timestamp`: Unix-время в секундах;
- `x-banku-nonce`: новый UUID на каждый запрос;
- `x-banku-signature`: hex HMAC-SHA256.

Строка для HMAC: `POST\n/api/bot/v1\n{timestamp}\n{nonce}\n{sha256_hex(body)}`. Сайт проверяет
подпись, окно ±90 секунд и сохраняет nonce в PostgreSQL для защиты от повтора. Секрет не передаётся
в URL, ответ не кешируется. Один и тот же секрет задаётся как `BANKU_SERVICE_SECRET` у бота и
`BANKU_BOT_SERVICE_SECRET` у сайта.

## Действия

| `action` | Вход                                                                                    | Результат                                                      |
| -------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `query`  | `operation`, `discord_user_id`, `guild_id`, необязательный `server_slug` и `check_code` | Только свои баланс, история, счёт или доступные персоналу чеки |
| `lease`  | без других полей                                                                        | До пяти заданий доставки с арендой на две минуты               |
| `ack`    | `id`, `lease_token`, `outcome`, необязательные `error_code`, `retry_seconds`            | Итог доставки или ограниченная повторная попытка               |

`query` сверяет Discord ID с OAuth-профилем, активный профиль и членство, включённую привязку Guild
к Minecraft-серверу, состояние сервера и существующий личный счёт. Для чеков дополнительно
проверяется банковское разрешение `checks.view` либо глобальный Owner. При нескольких допустимых
серверах ответ предлагает выбрать `server_slug`; финансовые данные другого сервера не возвращаются.

Сайт использует Supabase `service_role` **только внутри своего серверного API**. Бот не получает
этот ключ. Доступ к действиям `lease` и `ack` не даёт возможности создавать финансовые события.

## Доставка

Banku атомарно создаёт записи сайта и outbox при подтверждённых событиях. `claim` использует
`FOR UPDATE SKIP LOCKED`, токен аренды и лимит попыток. После ошибки Discord 429/5xx задание
повторяется; ошибка DM 403/404 может создать одно нейтральное fallback-сообщение на пользователя и
Guild в час. Отправка идёт после коммита банковской транзакции. Если подтверждение доставки
потеряно, Discord-сообщение может повториться. Источник банковской истины остаётся в Supabase Banku.
